How to use:

Go to your profile url on Rhythm Typer and copy the firebase uid at the end.

Example:
https://rhythm-typer.web.app/user/erzUUNuTTygEdnWK01MEZDQ8cZ23

->

erzUUNuTTygEdnWK01MEZDQ8cZ23

Paste that into user_id.txt

Run run.bat

After a few minutes, you'll get an output.csv that you should be able to import into spreadsheets.



FAQ

Q. I am getting "ModuleNotFoundError: No module named 'requests'".

A. Run the requirements.bat once and it's gone forever.
